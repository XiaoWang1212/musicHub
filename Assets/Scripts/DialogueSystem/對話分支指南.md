# 🎮 對話中插入選擇 - 完整指南

## 💡 概念說明

你現在可以在**對話進行中**插入選擇,選完後**接續不同對話分支**,同時改變好感度!

```
對話 A → 對話 B → 【選擇】 → 分支對話 C1 or C2 or C3 → 繼續...
                     ↓
                   選項 1 → 對話序列 X (好感度 +1)
                   選項 2 → 對話序列 Y (好感度 ±0)
                   選項 3 → 對話序列 Z (好感度 -1)
```

---

## 📋 Unity 設定步驟

### 步驟 1: 建立主對話序列

**建立檔案**: `Chapter4_Event1_Main`

```
Dialogues:
  [0] 大野陽斗: "我最近在練習一首新曲子..."
  [1] 大野陽斗: "但是節奏總是抓不好"
  [2] 大野陽斗: "你覺得...我該怎麼辦?" ← 這裡會出現選擇!
```

在 `Dialogue [2]` 設定:

```
Dialogue Data [2]:
├── Character Name: "大野陽斗"
├── Dialogue Text: "你覺得...我該怎麼辦?"
└── Choices (Size = 3)  ← 展開這裡
    ├── Element 0
    │   ├── Choice Text: "我可以幫你一起練習"
    │   ├── Branch Dialogue: "Branch_Help" ← 拖曳分支對話
    │   ├── Target Character: "大野陽斗"
    │   └── Relationship Effect: Increase (+1)
    ├── Element 1
    │   ├── Choice Text: "我不太懂音樂欸"
    │   ├── Branch Dialogue: "Branch_Neutral"
    │   ├── Target Character: "大野陽斗"
    │   └── Relationship Effect: None (0)
    └── Element 2
        ├── Choice Text: "你自己多練習就好了"
        ├── Branch Dialogue: "Branch_Cold"
        ├── Target Character: "大野陽斗"
        └── Relationship Effect: Decrease (-1)
```

---

### 步驟 2: 建立分支對話序列

建立 3 個分支對話檔案:

#### 📁 Branch_Help (支持分支)
```
Dialogues:
  [0] 大野陽斗 (開心): "真的嗎!太好了!"
  [1] 大野陽斗 (開心): "有你幫忙我一定能練好的"
  [2] 白石透羽: "那我們現在就開始吧"
```

#### 📁 Branch_Neutral (中立分支)
```
Dialogues:
  [0] 大野陽斗 (普通): "沒關係,我再自己想想辦法"
  [1] 白石透羽: "加油..."
```

#### 📁 Branch_Cold (冷淡分支)
```
Dialogues:
  [0] 大野陽斗 (難過): "...是嗎"
  [1] 大野陽斗 (難過): "我知道了..."
  [2] (旁白): 大野陽斗低下了頭,看起來有些失落
```

---

### 步驟 3: 連接到 ActManager

```
BaseActManager:
├── Act Dialogue Sequence: Chapter4_Event1_Main ← 主對話
└── Transition To Next Scene: 下一場景
```

**就這樣!** 系統會自動處理:
1. 播放主對話到選擇點
2. 顯示選項
3. 根據選擇播放對應分支
4. 改變好感度
5. 分支對話結束後轉場

## 🔧 進階技巧

### 技巧 1: 多層分支

你可以在分支對話中再加入選擇!

```
主對話 → 選擇 A
         ├─ 分支 1 → 選擇 B
         │           ├─ 分支 1-1
         │           └─ 分支 1-2
         ├─ 分支 2
         └─ 分支 3
```

**設定方式**:
1. 在 `Branch_1` 對話序列中的某個對話
2. 加入 `Choices` 並設定 `Branch Dialogue`

---

### 技巧 2: 共同結尾

如果分支對話結束後要合併到共同劇情:

```
主對話 → 選擇
         ├─ 分支 1 (短) ─┐
         ├─ 分支 2 (短) ─┼→ 共同結尾對話
         └─ 分支 3 (短) ─┘
```

**方法 A**: 在每個分支的最後一句設定選擇
```
Branch_1 最後一句:
└── Choices (Size = 1)
    └── Element 0
        ├── Choice Text: "繼續" (自動點擊)
        └── Branch Dialogue: Common_Ending
```

**方法 B**: 設定 `After Choice Dialogue`(在 ActManager)

---

### 技巧 3: 角色表情跟隨選擇

```
Element 0:
├── Choice Text: "我可以幫你一起練習"
├── Branch Dialogue: Branch_Help
├── Target Character: "大野陽斗"
├── Relationship Effect: Increase
└── Character Expression: "開心" ← 選擇後立即變表情
```

選擇瞬間角色表情會改變!

## 📝 實際範例模板

### 範例 1: 簡單二選一

**主對話**: `Ask_Hinata_Return`
```
Dialogues:
  [0] 山瀨日向: "我...我不知道該不該回去"
  [1] 白石透羽: "..." ← 這裡有選擇
      Choices:
        [A] "我希望你回來" → Branch_Support (+1)
        [B] "隨便你" → Branch_Ignore (-1)
```

**分支對話**:
- `Branch_Support`: 日向決定回來的對話
- `Branch_Ignore`: 日向更加迷茫的對話

---

### 範例 2: 三選一(好/中/壞)

**主對話**: `Conflict_Resolution`
```
Dialogues:
  [0] 久我靜真: "我覺得這個節奏應該快一點"
  [1] 大野陽斗: "可是我覺得慢一點比較有感覺"
  [2] 白石透羽: "..." ← 選擇點
      Choices:
        [A] "不如折衷一下?" → Branch_Compromise (大野+1, 久我+1)
        [B] "我支持靜真" → Branch_Support_Kuga (久我+1, 大野-1)
        [C] "我支持陽斗" → Branch_Support_Ohno (大野+1, 久我-1)
```

**注意**: 一個選擇可以影響多個角色!
只要設定 Target Character 為 "久我靜真",然後在下一個選擇項目再設一個影響 "大野陽斗"。

## ⚙️ 欄位說明

### DialogueData 中的 Choices

| 欄位 | 說明 | 必填 |
|------|------|------|
| Choice Text | 按鈕上的文字 | ✅ 必填 |
| Branch Dialogue | 選擇後播放的對話序列 | ✅ 建議填寫 |
| Next Dialogue Id | 如果沒有分支對話,跳到此 ID | ❌ 可選 |
| Target Character | 影響的角色 | ✅ 建議填寫 |
| Relationship Effect | Increase/None/Decrease | ✅ 必填 |
| Character Expression | 選擇後角色表情 | ❌ 可選 |

## 🎯 對話流程最佳實踐

### 推薦結構:
```
主對話 (5-10句)
  ↓
選擇點 (2-3個選項)
  ↓
分支對話 (3-5句)
  ↓
轉場 or 匯流
```

### 分支長度建議:
- **短分支** (1-3句): 適合情緒反應
- **中分支** (4-6句): 適合一般劇情分歧
- **長分支** (7+句): 適合重要劇情轉折

---

## 💡 小技巧

1. **用旁白連接**: 分支對話開頭用旁白描述氛圍
2. **表情先行**: 設定 Character Expression 讓反應更生動
3. **音效配合**: 在分支對話設定不同 Background Music
4. **Debug 測試**: 用 Context Menu 快速測試各分支
