# 🎯 快速參考 - 對話中插入選擇

## 3 步驟設定

### 1️⃣ 主對話加入選擇
```
Dialogue Data [最後一句]:
├── Dialogue Text: "你覺得呢?"
└── Choices (Size = 3) ← 展開設定
```

### 2️⃣ 設定選項
```
Element 0:
├── Choice Text: "我支持你" ✍️
├── Branch Dialogue: [拖曳對話序列] 📁
├── Target Character: "大野陽斗" 👤
└── Relationship Effect: Increase ↑
```

### 3️⃣ 建立分支對話序列
```
Create > Narrative Game > Dialogue Sequence
→ 命名: Branch_Support
→ 寫入對話內容
```

---

## 📊 完整流程

```
主對話
  ├─ [0] "對話 A"
  ├─ [1] "對話 B"
  └─ [2] "你覺得呢?" ← has Choices
         ↓
      【選項出現】
         ├─ 選項 1 → Branch_A (好感度+1)
         ├─ 選項 2 → Branch_B (好感度±0)
         └─ 選項 3 → Branch_C (好感度-1)
            ↓
         播放對應分支
            ↓
         轉場結束
```

---

## ⚡ 關鍵欄位

| 欄位 | 作用 |
|------|------|
| **Choice Text** | 按鈕文字 |
| **Branch Dialogue** | 分支對話序列 (優先) |
| **Target Character** | 影響的角色 |
| **Relationship Effect** | 好感度變化 |

---

## 💡 範例設定

```
主對話: Chapter4_Event1
  └─ Dialogue [2] 有 3 個選擇
      ├─ "幫助他" → Branch_Help (+1)
      ├─ "中立" → Branch_Neutral (0)
      └─ "拒絕" → Branch_Refuse (-1)

分支對話:
  📁 Branch_Help (3句話)
  📁 Branch_Neutral (2句話)
  📁 Branch_Refuse (2句話)
```

---

## ✅ 記住

- ✅ 對話有 Choices → 自動顯示選項
- ✅ Branch Dialogue → 接續分支對話
- ✅ Target Character + Effect → 改變好感度
- ✅ 分支結束 → 自動轉場
