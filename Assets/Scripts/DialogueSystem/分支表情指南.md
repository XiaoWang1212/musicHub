# 🎭 分支對話表情自動切換指南

## 💡 概念

現在你可以在**分支對話中直接設定表情**,系統會自動切換!

不需要:
- ❌ 新腳本
- ❌ ExpressionTriggerAsset
- ❌ 寫程式碼

只需要:
- ✅ 在對話序列中設定 `Characters` 和 `Expression`

---

## 📋 Unity 設定步驟

### 你的範例: 大野陽斗練習事件

#### 步驟 1: 建立分支對話 - Branch_Help (提高好感)

**檔案**: `Branch_Help_Ohno`

```
Dialogues:

[0] 白石透羽 說話
├── Use Multiple Characters: ✅ 勾選
├── Characters (Size = 2)
│   ├── Element 0
│   │   ├── Character Name: "白石透羽"
│   │   ├── Position: Left
│   │   ├── Dim Character: ❌ 不勾選 (說話者)
│   │   └── Expression: "平常"
│   └── Element 1
│       ├── Character Name: "大野陽斗"
│       ├── Position: Right
│       ├── Dim Character: ✅ 勾選 (聽者)
│       └── Expression: "" (保持原表情)
├── Character Name: "白石透羽"
└── Dialogue Text: "想一起試一下？我聽聽看哪裡卡。"

[1] 旁白
├── Is Narration: ✅ 勾選
├── Character Name: "" (留空)
└── Dialogue Text: "大野 陽斗 抬頭，明顯放鬆不少。"

[2] 大野陽斗 說話(表情切換!)
├── Use Multiple Characters: ✅ 勾選
├── Characters (Size = 2)
│   ├── Element 0
│   │   ├── Character Name: "白石透羽"
│   │   ├── Position: Left
│   │   ├── Dim Character: ✅ 勾選
│   │   └── Expression: "" (保持平常)
│   └── Element 1
│       ├── Character Name: "大野陽斗"
│       ├── Position: Right
│       ├── Dim Character: ❌ 不勾選 (說話者)
│       └── Expression: "喜" ← 自動切換表情!
├── Character Name: "大野陽斗"
└── Dialogue Text: "喔，好啊。有人一起試比較快解決。"
```

## 🎬 執行流程

```
播放主對話
  ├─ [0] "我最近在練習..."
  ├─ [1] "但是節奏抓不好"
  └─ [2] "你覺得怎麼辦?" → 顯示選擇
         ↓
玩家選擇 "我可以幫你一起練習"
  ↓ 好感度 +1
  ↓
切換到 Branch_Help_Ohno
  ├─ [0] 白石透羽(平常): "想一起試一下？..."
  │      → 大野陽斗(保持原表情)
  ├─ [1] 旁白: "大野 陽斗 抬頭..."
  └─ [2] 大野陽斗(喜): "喔，好啊..." ← 自動切換表情!
         ↓
對話結束 → 轉場
```

## ⚙️ Characters 欄位說明

### 完整設定範例

```
Dialogue Data [某一句]:

├── Use Multiple Characters: ✅ 必須勾選!
├── Characters (Size = 2)    ← 設定場上角色
│   ├── Element 0
│   │   ├── Character Name: "白石透羽"
│   │   ├── Position: Left
│   │   ├── Dim Character: ❌ (說話者不暗)
│   │   └── Expression: "平常" ← 表情名稱
│   └── Element 1
│       ├── Character Name: "大野陽斗"
│       ├── Position: Right
│       ├── Dim Character: ✅ (聽者變暗)
│       └── Expression: "喜" ← 會自動切換!
├── Character Name: "白石透羽" (說話者)
└── Dialogue Text: "對話文字"
```

## 💡 實用技巧

### 技巧 1: 表情漸變

如果要讓表情自然變化:

```
[0] 大野陽斗 (平常): "嗯...?"
[1] (旁白): "他似乎想到了什麼"
[2] 大野陽斗 (開心): "我懂了!" ← 從平常變開心
```

---

### 技巧 2: 多人反應

同時顯示多個角色的表情變化:

```
[0] 白石透羽宣布決定
├── Characters (Size = 3)
│   ├── [0] 白石透羽 (Center, 不暗, "平常")
│   ├── [1] 大野陽斗 (Left, 暗, "驚訝") ← 同時反應
│   └── [2] 久我靜真 (Right, 暗, "思考") ← 同時反應
```

---

### 技巧 3: 空字串保持原表情

如果不想改變表情:

```
Expression: "" ← 留空,保持上一句的表情
```

---

### 技巧 4: 旁白配合表情

```
[0] 大野陽斗 (平常): "我..."
[1] (旁白): "他突然停頓了"
[2] 大野陽斗 (難過): "對不起" ← 旁白後表情變化
```

## ✅ 檢查清單

分支對話設定完成後確認:

- [ ] 需要表情的對話有勾選 `Use Multiple Characters`
- [ ] `Characters` Size 已設定(至少 1 個)
- [ ] 每個角色的 `Character Name` 正確
- [ ] `Expression` 有填寫(或留空保持)
- [ ] 說話者的 `Dim Character` 不勾選
- [ ] 聽者的 `Dim Character` 勾選
- [ ] 主對話的選擇有設定 `Branch Dialogue`
