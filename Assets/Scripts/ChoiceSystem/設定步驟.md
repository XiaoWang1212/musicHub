# 🎮 好感度系統設定步驟

## 📋 系統架構說明

你的好感度系統使用**單例模式 (Singleton Pattern)**,跟 `SceneTransitionManager` 一樣:

```
MainMenu Scene
├── RelationshipManager (DontDestroyOnLoad) ← 放這裡!
│   └── 跟著玩家整個遊戲過程
│
Act1/Act2/Act3 Scene
└── 各種 EventManager
    └── 透過 RelationshipManager.Instance 存取
```

---

## 🔧 Unity 設定步驟

### 步驟 1: 在 MainMenu 場景新增 RelationshipManager

1. 開啟 **MainMenu** 場景
2. 在 Hierarchy 右鍵 → Create Empty
3. 命名為 `RelationshipManager`
4. 拖曳 `RelationshipManager.cs` 腳本到這個物件上
5. 在 Inspector 中設定:
   - ✅ Increase Amount: `1` (好選項 +1)
   - ✅ Decrease Amount: `-1` (壞選項 -1)
   - ✅ Enable Debug Log: `true`

**重要**: 不需要在 Act1/Act2/Act3 場景中再放 RelationshipManager!

---

### 步驟 2: 設定 ChoiceManager

在**每個有選項的場景** (Act1/Act2/Act3):

1. 找到場景中的 `ChoiceManager` 物件
2. 在 Inspector 中:
   - ✅ **不需要**手動拖曳 RelationshipManager
   - ChoiceManager 會自動透過 `RelationshipManager.Instance` 存取

---

### 步驟 3: 建立事件管理器

當你需要顯示選項時,參考範例:

```csharp
public class Chapter4Event1Manager : MonoBehaviour
{
    public ChoiceManager choiceManager; // 在 Inspector 拖曳
    
    void ShowChoices()
    {
        // 檢查系統
        if (RelationshipManager.Instance == null)
        {
            Debug.LogError("找不到 RelationshipManager!");
            return;
        }
        
        // 建立選項
        ChoiceData[] choices = new ChoiceData[3];
        
        // 選項 A: 好選項 (+1)
        choices[0] = new ChoiceData
        {
            choiceText = "我覺得你彈得很好",
            targetCharacter = "大野陽斗",
            relationshipEffect = RelationshipEffect.Increase // +1
        };
        
        // 選項 B: 中立 (0)
        choices[1] = new ChoiceData
        {
            choiceText = "我不確定",
            targetCharacter = "大野陽斗",
            relationshipEffect = RelationshipEffect.None // 0
        };
        
        // 選項 C: 壞選項 (-1)
        choices[2] = new ChoiceData
        {
            choiceText = "你需要更多練習",
            targetCharacter = "大野陽斗",
            relationshipEffect = RelationshipEffect.Decrease // -1
        };
        
        choiceManager.ShowChoices(choices);
    }
}
```

## 🎯 存取方式

### ✅ 正確做法 (使用單例)

```csharp
// 取得好感度
int value = RelationshipManager.Instance.GetRelationshipValue("大野陽斗");

// 設定旗標
RelationshipManager.Instance.SetStoryFlag("hinata_returned", true);

// 取得總好感度
int total = RelationshipManager.Instance.GetTotalRelationship();

// 判定結局
int ending = RelationshipManager.Instance.DetermineEnding();
```

### ❌ 錯誤做法 (不要用 public 變數)

```csharp
// ❌ 不要這樣做
public RelationshipManager relationshipManager;

void Start()
{
    relationshipManager.ModifyRelationship(...); // 錯誤!
}
```

## 🧪 測試方法

### 方法 1: Context Menu (最簡單)

1. 在 Hierarchy 選擇 `RelationshipManager`
2. 在 Inspector 右上角點選 `...` (三個點)
3. 選擇:
   - **顯示當前狀態**: 查看所有好感度和旗標
   - **重置所有數據**: 清空所有資料重新測試

### 方法 2: Debug Log

執行遊戲時,Console 會自動顯示:

## 🎬 完整流程範例

### 第四章事件 1

```csharp
using UnityEngine;

public class Chapter4Event1Manager : MonoBehaviour
{
    public ChoiceManager choiceManager;
    public DialogueManager dialogueManager;
    
    void Start()
    {
        // 訂閱選項事件
        ChoiceManager.OnChoiceMade += HandleChoiceMade;
    }
    
    void OnDestroy()
    {
        // 取消訂閱
        ChoiceManager.OnChoiceMade -= HandleChoiceMade;
    }
    
    // 當對話結束時呼叫
    public void OnDialogueEnd()
    {
        ShowChoices();
    }
    
    void ShowChoices()
    {
        if (RelationshipManager.Instance == null)
        {
            Debug.LogError("找不到 RelationshipManager!");
            return;
        }
        
        ChoiceData[] choices = new ChoiceData[3];
        
        choices[0] = new ChoiceData
        {
            choiceText = "我覺得你彈得很好",
            targetCharacter = "大野陽斗",
            relationshipEffect = RelationshipEffect.Increase
        };
        
        choices[1] = new ChoiceData
        {
            choiceText = "我不確定欸",
            targetCharacter = "大野陽斗",
            relationshipEffect = RelationshipEffect.None
        };
        
        choices[2] = new ChoiceData
        {
            choiceText = "你可能需要更多練習",
            targetCharacter = "大野陽斗",
            relationshipEffect = RelationshipEffect.Decrease
        };
        
        choiceManager.ShowChoices(choices);
    }
    
    void HandleChoiceMade(ChoiceData choice)
    {
        Debug.Log($"玩家選擇了: {choice.choiceText}");
        
        // ChoiceManager 已經自動修改好感度了
        // 這裡可以繼續後續劇情
        
        // 例如: 播放後續對話
        // dialogueManager.StartDialogue(nextDialogueSequence);
    }
}
```

## ⚠️ 常見問題

### Q: 為什麼要放在 MainMenu?

**A**: 因為需要跨場景保存資料。如果放在 Act1/Act2/Act3,切換場景時資料會遺失。

---

### Q: 每個 Act 都要放 RelationshipManager 嗎?

**A**: 不需要! 只在 **MainMenu** 放一個就好。系統會自動跟著玩家到所有場景。

---

### Q: 如果忘記放在 MainMenu 會怎樣?

**A**: Console 會顯示錯誤:
```
[RelationshipManager] 場景中找不到 RelationshipManager! 請在 MainMenu 場景中新增!
```

---

### Q: 怎麼確認系統有正常運作?

**A**: 檢查 Hierarchy:

執行遊戲後,你會在 Hierarchy 最上方看到:

```
DontDestroyOnLoad
└── RelationshipManager ← 這個表示成功!
```
