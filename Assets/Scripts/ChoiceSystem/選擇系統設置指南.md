# 🎮 選擇系統設置指南

## 📋 系統概述

這個選擇系統讓你可以在劇情中創建選項，影響角色好感度並觸發不同的後續對話。

## 🔧 設置步驟

### 1. 場景基礎設置

1. **創建場景管理器**：
   - 使用 `OhnoPracticeSceneManager` 或繼承 `BaseActManager`
   - 設定 `CharacterManager`、`ChoiceManager`、`RelationshipManager`

2. **UI設置**：
   - 創建選擇面板 (Choice Panel)
   - 設定選項按鈕預製體 (Choice Button Prefab)
   - 可選：添加好感度UI (RelationshipUI)

### 2. 組件配置

#### ChoiceManager 設置：
```
Choice Panel: 選擇面板GameObject
Choice Button Container: 按鈕容器Transform
Choice Button Prefab: 按鈕預製體
Relationship Manager: 好感度管理器
```

#### RelationshipManager 設置：
```
Character Relationships: 角色列表
- 大野陽斗 (初始好感度: 50)
- 久我靜真 (初始好感度: 50)
- 神崎蓮 (初始好感度: 50)
- 白石透羽 (初始好感度: 50)

Increase Amount: 10 (好感度增加值)
Decrease Amount: -5 (好感度減少值)
```

### 3. 大野陽斗練習場景設置

#### OhnoPracticeSceneManager 配置：
```
【Basic Settings】
Act Dialogue Sequence: 主要對話序列
Transition To Next Scene: 轉場觸發器
Character Manager: 角色管理器
Choice Manager: 選擇管理器  
Relationship Manager: 好感度管理器

【Character Names】
Ohno Character Name: "大野陽斗"
Player Character Name: "白石透羽"

【Dialogue Sequences】
Pre Choice Dialogue: 選擇前對話
Choice A Dialogue: 選項A後續對話（好感度+）
Choice B Dialogue: 選項B後續對話（好感度不變）
Choice C Dialogue: 選項C後續對話（好感度-）

【Audio】
Guitar Audio Source: 音效播放器
Guitar Riff Sound: 吉他成功音效
Guitar Mistake Sound: 吉他失誤音效
```

## 🎯 使用方式

### 方式1：使用預設場景管理器
1. 在場景中放置 `OhnoPracticeSceneManager`
2. 設定所有必要組件引用
3. 創建對話序列資產
4. 系統會自動處理選擇邏輯

### 方式2：自定義場景
```csharp
// 在你的場景管理器中
public class MySceneManager : BaseActManager
{
    void ShowMyChoices()
    {
        ChoiceData[] choices = new ChoiceData[]
        {
            new ChoiceData
            {
                choiceText = "選項文字",
                targetCharacter = "角色名稱",
                relationshipEffect = RelationshipEffect.Increase,
                characterExpression = "表情名稱"
            }
        };
        
        ShowChoices(choices);
    }
}
```

## 🎭 角色表情對應

確保在 CharacterManager 中設置這些表情：
- **平常** - 普通表情
- **喜** - 開心表情  
- **不爽** - 不滿表情
- **苦惱** - 困擾表情

## 🎵 音效設置

為場景添加音效增強體驗：
- **guitarRiffSound** - 成功彈奏音效
- **guitarMistakeSound** - 彈錯音效

## 📊 好感度系統

### 好感度等級：
- **敵意** (0-19)
- **中性** (20-39) 
- **友好** (40-59)
- **親近** (60-79)
- **親密** (80-100)

### 好感度UI：
- 按 `R` 鍵切換顯示
- 顯示每個角色的數值和等級
- 顏色代表不同等級

## 🔄 事件流程

1. **場景開始** → 背景淡入 → 角色表情設定
2. **預對話播放** → 對話結束
3. **顯示選項** → 玩家選擇
4. **應用效果** → 好感度變化 → 角色表情變化
5. **後續對話** → 場景結束

## ⚙️ 除錯功能

### RelationshipManager：
- 右鍵選單 → "顯示好感度狀態"
- 右鍵選單 → "重置所有好感度"

### OhnoPracticeSceneManager：
- 右鍵選單 → "測試顯示選項"
- 右鍵選單 → "顯示好感度狀態"

## 🎯 完整範例設置

1. **場景結構**：
   ```
   Scene
   ├── Canvas
   │   ├── ChoicePanel (ChoiceManager)
   │   └── RelationshipPanel (RelationshipUI)
   ├── CharacterManager
   ├── RelationshipManager  
   └── OhnoPracticeSceneManager
   ```

2. **對話序列**：
   - 創建4個 DialogueSequenceAsset
   - 分別設為預對話和3個選項後續

3. **測試流程**：
   - 播放場景
   - 等待選項出現
   - 選擇不同選項測試效果
   - 按R查看好感度變化
