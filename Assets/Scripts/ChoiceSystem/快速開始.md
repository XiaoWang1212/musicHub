# 🎮 快速開始 - 3 步驟設定選擇

## 📦 步驟 1: 建立 Choice Sequence Asset

**Unity 操作**:
```
Project 視窗右鍵
→ Create 
→ MusicHub 
→ Choice Sequence
→ 命名: "Chapter4_Event1_Choices"
```

---

## ✏️ 步驟 2: 編輯選項

**Inspector 設定**:
```
Choice Description: "第四章事件1"

Choices (Size = 3)

Element 0:
  Choice Text: "我覺得你彈得很好"
  Target Character: "大野陽斗"
  Relationship Effect: Increase
  
Element 1:
  Choice Text: "我不確定欸"
  Target Character: "大野陽斗"
  Relationship Effect: None
  
Element 2:
  Choice Text: "你需要更多練習"
  Target Character: "大野陽斗"
  Relationship Effect: Decrease
```

---

## 🔗 步驟 3: 連接到 ActManager

**Hierarchy 操作**:
```
1. 選擇你的 ActManager 物件
2. 在 Inspector 找到 "選擇系統(可選)"
3. 拖曳 "Chapter4_Event1_Choices" 到 "Choice Sequence"
```

**完成!** 🎉

---

## 🎬 執行效果

```
遊戲開始
  ↓
播放 Act Dialogue Sequence (前置對話)
  ↓
對話結束,自動偵測到有 Choice Sequence
  ↓
顯示 3 個選項按鈕
  ↓
玩家點選選項
  ↓
好感度自動變化 (±1 或 0)
  ↓
如果有設定 After Choice Dialogue,播放它
  ↓
轉場到下一場景
```

---

## 💡 進階: 每個選項不同後續對話

**在 Choice Sequence Asset 中**:

```
Element 0:
  Choice Text: "支持他"
  Target Character: "大野陽斗"
  Relationship Effect: Increase
  Follow Up Dialogue: "支持後的對話" ← 拖曳對話序列
  
Element 1:
  Choice Text: "反對他"
  Target Character: "大野陽斗"
  Relationship Effect: Decrease
  Follow Up Dialogue: "反對後的對話" ← 拖曳對話序列
```

系統會自動根據玩家選擇播放對應對話!

---

## ⚙️ 選項欄位說明

| 欄位 | 說明 | 必填 |
|------|------|------|
| Choice Text | 按鈕上顯示的文字 | ✅ 必填 |
| Target Character | 影響的角色名稱 | ✅ 必填 |
| Relationship Effect | Increase(+1) / None(0) / Decrease(-1) | ✅ 必填 |
| Follow Up Dialogue | 選擇後播放的對話序列 | ❌ 可選 |
| Character Expression | 選擇後角色表情變化 | ❌ 可選 |
