# 選擇與好感度系統 - 完整使用指南

## 📋 系統總覽

你的遊戲現在有完整的選擇與好感度系統,可以處理:
- ✅ 角色好感度追蹤 (5 個角色)
- ✅ 選項顯示與互動
- ✅ 劇情標記記錄
- ✅ 結局判定 (3 種結局)

## 🎯 核心組件

### 1. RelationshipManager (好感度管理器)
**位置:** `Assets/Scripts/ChoiceSystem/RelationshipManager.cs`

**功能:**
- 追蹤 5 個角色的好感度
- 管理劇情標記 (例如: 日向是否回歸)
- 計算好感度總和
- 判定結局類型

**重要方法:**
```csharp
// 修改好感度
ModifyRelationship(characterName, effect)

// 取得好感度
GetRelationshipValue(characterName)

// 好感度總和
GetTotalRelationship()

// 劇情標記
SetStoryFlag(flagId, value)
GetStoryFlag(flagId)

// 結局判定
DetermineEnding()  // 返回 1/2/3
```

---

### 2. ChoiceManager (選擇管理器)
**位置:** `Assets/Scripts/ChoiceSystem/ChoiceManager.cs`

**功能:**
- 顯示選項按鈕
- 處理玩家點擊
- 自動套用好感度變化
- 播放選擇動畫

**使用方法:**
```csharp
// 創建選項
ChoiceData[] choices = new ChoiceData[] { ... };

// 顯示選項
choiceManager.ShowChoices(choices);
```

---

### 3. ChoiceData (選項資料)
**位置:** `Assets/Scripts/DialogueSystem/DialogueData.cs`

**結構:**
```csharp
public class ChoiceData
{
    public string choiceText;              // 按鈕文字
    public string targetCharacter;         // 影響的角色
    public RelationshipEffect relationshipEffect;  // None/Increase/Decrease
    public string characterExpression;     // 角色表情
    public DialogueSequenceAsset followUpDialogue; // 後續對話
}
```

---

## 🎮 使用流程

### 基本流程

```
1. 播放初始對話
    ↓
2. 顯示選項 (ChoiceManager.ShowChoices)
    ↓
3. 玩家點擊選項
    ↓
4. ChoiceManager 自動處理:
   - 修改好感度
   - 變更角色表情
   - 隱藏選項
   - 觸發 OnChoiceMade 事件
    ↓
5. 播放後續對話
```

## 📝 實作範例

### 範例 1: 簡單選擇 (單一角色好感度)

```csharp
public class Chapter4Event1Manager : MonoBehaviour
{
    public ChoiceManager choiceManager;
    
    void ShowChoices()
    {
        ChoiceData[] choices = new ChoiceData[]
        {
            // 選項 A: +10 好感
            new ChoiceData
            {
                choiceText = "想一起試一下？我聽聽看哪裡卡。",
                targetCharacter = "大野陽斗",
                relationshipEffect = RelationshipEffect.Increase
            },
            
            // 選項 B: ±0 好感
            new ChoiceData
            {
                choiceText = "先休息一下吧。",
                targetCharacter = "大野陽斗",
                relationshipEffect = RelationshipEffect.None
            },
            
            // 選項 C: -5 好感
            new ChoiceData
            {
                choiceText = "你這段已經卡三天了吧。",
                targetCharacter = "大野陽斗",
                relationshipEffect = RelationshipEffect.Decrease
            }
        };
        
        choiceManager.ShowChoices(choices);
    }
}
```

### 範例 2: 巢狀選擇 (選擇後觸發選擇)

```csharp
public class Chapter3Act2Manager : MonoBehaviour
{
    private bool askedReason = false;
    
    // 第一層選擇
    void ShowFirstChoice()
    {
        ChoiceData[] choices = new ChoiceData[]
        {
            new ChoiceData
            {
                choiceText = "為什麼……你會退出？",
                relationshipEffect = RelationshipEffect.None
            },
            new ChoiceData
            {
                choiceText = "（不詢問）",
                relationshipEffect = RelationshipEffect.None
            }
        };
        
        choiceManager.ShowChoices(choices);
    }
    
    void HandleChoiceMade(int choiceIndex)
    {
        if (!askedReason)
        {
            if (choiceIndex == 0)
            {
                // 選擇詢問 → 顯示第二層選擇
                askedReason = true;
                relationshipManager.SetStoryFlag("asked_hinata_reason", true);
                ShowSecondChoice();
            }
            else
            {
                // 不詢問 → 日向不回來
                relationshipManager.SetStoryFlag("hinata_returned", false);
            }
        }
        else
        {
            // 處理第二層選擇...
        }
    }
}
```

### 範例 4: 結局判定

```csharp
public class EndingManager : MonoBehaviour
{
    public void DetermineAndLoadEnding()
    {
        int endingType = relationshipManager.DetermineEnding();
        
        switch (endingType)
        {
            case 1:
                // 完美結局
                LoadScene("Ending1_Perfect");
                break;
                
            case 2:
                // 普通結局
                bool hinataReturned = relationshipManager.GetStoryFlag("hinata_returned");
                
                if (hinataReturned)
                {
                    LoadScene("Ending2_WithHinata");
                }
                else
                {
                    LoadScene("Ending2_WithoutHinata");
                }
                break;
                
            case 3:
                // 壞結局
                LoadScene("Ending3_Disbandment");
                break;
        }
    }
}
```

## 🎯 好感度計算

### 角色列表
1. 大野陽斗 (初始 0)
2. 久我靜真 (初始 0)
3. 山瀨日向 (初始 0)
4. 高宮芽依 (初始 0)
5. 白石透羽 (不計入總和)

### 變化量
- `RelationshipEffect.Increase` = **+10**
- `RelationshipEffect.None` = **±0**
- `RelationshipEffect.Decrease` = **-5**

### 總和計算
只計算四位樂團成員 (不包括白石透羽):
```
總和 = 大野 + 久我 + 山瀨 + 高宮
```

### 達成完美結局的路徑

**第四章 (4 個事件):**
- 事件 1 (大野): 選 A (+10)
- 事件 2 (久我): 選 A (+10)
- 事件 3 (山瀨): 選 A (+10)
- 事件 4 (高宮): 選 A (+10)
**小計: 40 分**

**第五章 (2 個事件):**
- 事件 1 (節奏衝突): 選 A - 折衷 (大野+10, 久我+10, 山瀨+10)
- 事件 2 (舞台動作): 選 A - 平衡 (大野+10, 山瀨+10)
**小計: 50 分**

**第三幕第二章 (天台):**
- 必須詢問理由
- 必須支持日向 (山瀨+10)
**小計: 10 分**

**總計: 40 + 50 = 90 分 ✅**

## 💡 常見問題

### Q: 為什麼好感度沒有變化?
A: 檢查:
1. `ChoiceManager` 是否引用了 `RelationshipManager`
2. `targetCharacter` 名稱是否正確 (必須完全一致)
3. `relationshipEffect` 是否設為 `None`

### Q: 如何測試特定結局?
A: 使用 Context Menu:
1. 右鍵 `RelationshipManager` → 重置所有數據
2. 手動設定好感度和標記
3. 右鍵 `EndingManager` → 檢查結局條件

### Q: 如何追加新角色?
A: 在 `RelationshipManager.InitializeCharacters()` 的 `defaultCharacters` 陣列中添加新角色名稱。
